# 🚀 Featured Projects

## 🤖 AI Job Matcher

A Python and Streamlit application that compares résumés with job descriptions using TF-IDF, cosine similarity, and technical skill-gap analysis.

### ✨ Highlights

- 📄 Supports PDF, DOCX, and TXT résumé uploads
- 🎯 Produces text-similarity, skill-coverage, and overall match scores
- ✅ Identifies matched and missing technical skills
- 🧪 Includes automated tests and GitHub Actions CI
- 🐳 Includes Docker support and container health checks
- ☁️ Deployed publicly with Streamlit Community Cloud

### 🛠️ Stack

`Python` `Streamlit` `scikit-learn` `Pandas` `Pytest` `Docker` `GitHub Actions`

## ☕ Fenjan Café Operations Dashboard

An interactive business-intelligence dashboard built with synthetic café sales and inventory data.

### ✨ Highlights

- 📈 Tracks revenue, gross profit, orders, margin, and average order value
- 🔎 Filters analytics by date, location, and product category
- 🏆 Analyzes product, hourly, and location performance
- 📦 Monitors inventory and generates automatic reorder alerts
- 🗄️ Uses SQLite and SQL-powered analytics
- 🧪 Includes automated tests, Docker validation, and GitHub Actions CI
- ☁️ Deployed publicly with Streamlit Community Cloud

### 🛠️ Stack

`Python` `SQL` `SQLite` `Pandas` `Plotly` `Streamlit` `Pytest` `Docker`
